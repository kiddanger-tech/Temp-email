How to write a web page with HTML

Every website you have ever opened is built on HTML. This page walks through the parts you need to write your own, with small examples you can copy.

What HTML is

HTML stands for HyperText Markup Language. It is not a programming language. It does not calculate or make decisions. It describes what things are on a page: this is a heading, this is a paragraph, this is a link.

You write it in a plain text file, save it with the ending .html, and open it in a browser. That is all you need. No install, no special software. Notepad works.

Three languages build most pages. HTML is the content, CSS is the look, JavaScript is the behavior. This guide covers HTML and a little CSS.

The basic structure

Most of HTML is made of tags. A tag is a word inside angle brackets. Most tags come in pairs: one to open, one to close (with a slash). Together with what is between them, they are called an element.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello</h1>
    <p>This is my page.</p>
  </body>
</html>

What each part does

<!DOCTYPE html> tells the browser this is modern HTML. <html> wraps everything. <head> holds information about the page, like the title shown on the browser tab. <body> holds everything people actually see.

Headings, paragraphs and emphasis

Headings go from <h1> (biggest, most important) down to <h6>. Use one <h1> per page. Paragraphs use <p>.

<h1>Main title</h1>
<h2>A section</h2>
<p>Some text with <strong>bold</strong> and <em>italic</em> words.</p>
What the browser shows

Main title

A section

Some text with bold and italic words.

One thing that surprises beginners: the browser ignores extra spaces and line breaks in your file. If you want a line break inside a paragraph, use <br>. If you want a new paragraph, use another <p>.

Links and images

Both use attributes, extra information placed inside the opening tag as name="value".

<a href="https://www.wikipedia.org">Go to Wikipedia</a>

<img src="photo.jpg" alt="A group of students in a lab">
What the browser shows
Go to Wikipedia

href is where the link goes. src is the image file. The alt text is read aloud by screen readers and shown if the image fails to load, so always write something useful there. The image file must sit in the same folder as your HTML file, or you must give the correct path.

Lists and tables

<ul>
  <li>Rice</li>
  <li>Beans</li>
</ul>

<ol>
  <li>Open Notepad</li>
  <li>Type your code</li>
</ol>
What the browser shows
  • Rice
  • Beans
  1. Open Notepad
  2. Type your code

<ul> is a bulleted list, <ol> is numbered. Each item is an <li>.

Tables are built row by row:

<table>
  <tr><th>Tag</th><th>Meaning</th></tr>
  <tr><td>p</td><td>paragraph</td></tr>
  <tr><td>a</td><td>link</td></tr>
</table>
What the browser shows
TagMeaning
pparagraph
alink

<tr> is a row, <th> a header cell, <td> a normal cell. Use tables for data, not for page layout.

Forms

Forms collect input from the user. The pieces are <input> fields, each with a <label>.

<form>
  <label for="name">Your name</label>
  <input type="text" id="name">

  <label for="grade">Grade</label>
  <select id="grade">
    <option>A</option>
    <option>B</option>
  </select>

  <button type="submit">Send</button>
</form>
What the browser shows

On its own, a form does not send the data anywhere useful. For that you need a server or a form service, which is beyond plain HTML.

Adding style with CSS

Plain HTML looks plain. CSS changes colors, fonts and spacing. The simplest way is a <style> block in the <head>.

<head>
  <style>
    body { font-family: Arial; background: #f4f4f4; }
    h1   { color: darkred; }
    .box { border: 2px solid black; padding: 10px; }
  </style>
</head>
<body>
  <h1>Styled title</h1>
  <p class="box">A paragraph with a border.</p>
</body>
What the browser shows
Styled title
A paragraph with a border.

The part before the braces says what to style. A name with a dot, like .box, targets any element that has class="box".

Mistakes everyone makes

Forgetting to close a tag

If you open a <p> and never close it, the browser guesses, and the page can look wrong in odd ways.

Wrong file path for an image

If the picture does not show, check the file name, the capital letters, and the folder. Photo.JPG and photo.jpg are different files on many systems.

Saving as .txt

If your file is named index.html.txt, the browser shows your code as text instead of a page. Turn on file extensions to check.

Quotes

Use straight quotes " in attributes. Curly quotes copied from a word processor will break them.
